# サンプラー PWA v9 — 音声復旧・動画取込対応版

iOS 12向けの構文・タッチ対応に加え、音声の有効化、縦音量バー、AAC音声付きMP4/MOVからの音声取込を改善した版です。

新しい`audio/`フォルダー、`js/media-unlock.js`、`js/video-audio.js`も含めて、全体を現在の配信先へ上書きしてください。ビルドやnpm installは不要です。メニューの更新、または`update-ios12.html`から更新し、メニューに「v9」が出ることを確認します。

初回は消音スイッチを解除し、端末とアプリの音量を上げて「再生」をタップしてください。メニューに「テスト音を鳴らす」を追加しました。

動画取込では、映像を保存せずAAC音声トラックだけを取り出します。音声のない動画、分割形式・保護付き・非対応音声形式などには対応しません。元ファイル200MB・音声10分までです。取込の失敗で既存PADの音源は置き換えません。

詳細・更新手順・制約は[IOS12-NOTES.md](IOS12-NOTES.md)を参照してください。iOS実機での動作保証はまだありません。

Node.jsで次を実行すると、依存パッケージ不要で74件の自動テストを確認できます。

```sh
node --experimental-vm-modules --test tests/*.test.mjs
```

または`npm test`を実行してください。今回の検証結果は`validation/`にあります。`tests/`・`validation/`・ドキュメントはアプリ実行には不要です。実行ファイルの変更時には`sw.js`のキャッシュ名とSHELLを更新してください。
