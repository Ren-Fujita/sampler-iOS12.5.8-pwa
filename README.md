# サンプラー PWA — iOS 12 Safari対応版（v8）

iOS 12でPAD生成と音量操作が初期化されない原因となるJavaScript構文を修正し、旧Safari向けのタッチ操作・ファイル読込・音声デコード・CSSの代替処理を追加しました。現在のブラウザの経路と既存の保存・バックアップ形式も維持しています。

詳しい変更点、検証結果、制約は[IOS12-NOTES.md](IOS12-NOTES.md)を参照してください。iOS 12実機での最終確認は未実施です。

## 公開

このフォルダーの中身全体を、現在のGitHub Pagesなどの`index.html`がある場所へ上書きします。`js/`と`icons/`もすべて必要です。ビルドやnpm installは不要です。アプリはHTTP/HTTPSで配信し、オフライン起動にはHTTPSを使用してください。

旧版のメニューから更新を適用できます。メニューも動かない場合は、同じ配信先の`update-ios12.html`を開いて更新を確認・適用できます。保存データの削除は不要です。

初回は「再生」をタップして音を有効にしてください。iOS 12では消音スイッチを解除し、端末側の音量も上げてください。旧Safariのバックアップ書き出しでは手動保存リンクを表示しますが、OS上の「ファイルに保存」が利用できるかは端末で確認が必要です。

## 維持した機能

10バンク×12PAD、初期音、GATE/LOOP、試聴、取込、音源名・トリム・音量・ピッチの編集、編集再生・一時停止・波形シーク、キーボード操作、細かな主音量とミュート、IndexedDB保存・復元、旧・新バックアップ、PWA更新・オフライン起動を維持しています。

## 検証

Node.jsで`npm test`を実行できます。依存パッケージは不要です。58件すべて成功しました。`npm`のない環境では次を実行してください。

```sh
node --experimental-vm-modules --test tests/*.test.mjs
```

さらにWindowsのChromiumで、通常経路とiOS 12にないAPIを無効にした経路、更新補助ページを確認しました。`validation/`に結果と画面を同梱しています。これはiOS 12実機・聴感・発音遅延・OSの保存画面を保証する試験ではありません。

`tests/`、`validation/`、ドキュメントはアプリ実行には不要です。実行ファイルを変更する際は`sw.js`のキャッシュ名を更新し、新しい依存ファイルをSHELLへ登録してください。
